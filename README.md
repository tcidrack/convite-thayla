# Convite de aniversário da Thayla — tema Bailarina

Convite digital (Vite + React + Supabase): envelope, convite com confirmação de presença e
lista de confirmados em `/admin`.

- **`frontend/`** — o site. Como rodar, editar e publicar: [`frontend/README.md`](frontend/README.md)
- **`database.sql`** — tabela e função de confirmação (rodar no SQL Editor do Supabase)
- **`imagens/`** — artes originais e o vídeo da bailarina; os scripts de `frontend/arte/`
  geram a partir delas as versões otimizadas de `frontend/public/assets/`
